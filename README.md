## 🚀 কীভাবে ওয়েবসাইট রান ও প্রিভিউ করবেন? (How to Run Locally)

### পদ্ধতি ১ (সবচেয়ে সহজ):
- যেকোনো ব্রাউজারে (Chrome, Edge, Firefox) সরাসরি `index.html` ফাইলটিতে ডাবল-ক্লিক করলেই ওয়েবসাইটটি খুলে যাবে। কোনো সার্ভার ইন্সটল করার দরকার নেই!

### পদ্ধতি ২ (Node.js সার্ভারের মাধ্যমে):
- টার্মিনাল বা PowerShell-এ রান করুন:
  ```bash
  node server.js
  ```
- এরপর যেকোনো ব্রাউজারে যান: `http://localhost:3456/`

## 🌐 সাধারণ হোস্টিংয়ে ডিপ্লয়মেন্ট করার নিয়ম (How to Deploy to Hosting)

যেহেতু এই ওয়েবসাইটটি **১০০% পিওর ফ্রন্ট-এন্ড (Pure Static Front-End: HTML5, CSS3, Bootstrap 5, JavaScript, jQuery)** দিয়ে তৈরি এবং কোনো জটিল ব্যাকএন্ড বা ডেটাবেস নেই:

1. **cPanel / DirectAdmin / Shared Hosting:**
   - আপনার হোস্টিং কন্ট্রোল প্যানেলে (cPanel) লগইন করুন।
   - **File Manager**-এ যান এবং `public_html` ফোল্ডারে ঢুকুন।
   - এই পুরো ফোল্ডারের সমস্ত ফাইল ও `assets` ফোল্ডার সরাসরি আপলোড করে দিন।
   - ব্যস! আপনার ওয়েবসাইট তৎক্ষণাৎ লাইভ হয়ে যাবে।

2. **Netlify / Vercel / GitHub Pages:**
   - ফোল্ডারটি সরাসরি ড্র্যাগ-অ্যান্ড-ড্রপ (Drag & Drop) করে দিলেই ১ মিনিটে বিনামূল্যে লাইভ হয়ে যাবে।
